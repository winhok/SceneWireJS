# Review visual output

Inspect project intent and engine rationale. Run `scenewire render-check project.json --frames <representative-and-boundary-frames>`; use capture/contact-sheet to retain readable visual evidence. Open the images and inspect hierarchy, text readability, reference language, compositing, clipping, transitions, visual continuity and coherence across engines. Inspect more frames only where findings warrant it.

Report findings with scene/frame, observed defect and likely scope. A review request does not authorize edits. If fixes are authorized, revise narrowly, retain before/after evidence and repeat relevant capture/checks. Keyframes cannot prove continuous motion or playback; keep those conclusions pending unless a full video was actually continuously reviewed. Technical repeatability does not imply aesthetic approval, formal acceptance or release.
